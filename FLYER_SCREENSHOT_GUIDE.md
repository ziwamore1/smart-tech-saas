# Smart Tech Flyer — Screenshot Capture Guide

Follow these steps to capture every screen you need. Use a **1920x1080** browser window for consistency. Clean up any test/development data if visible (names, scores). Export as **PNG**.

---

## Step 0: Preparation

1. Log in as **Director** (full access to all screens)
2. Set browser zoom to **100%** and window to **1920x1080**
3. Use **Chrome or Edge** for consistent rendering
4. If possible, use a school that has **real-looking data** — classes, students with varied scores, published results

---

## Screenshots to Capture

### 1. Login Page
**File:** `01-login.png`
- Navigate to the login page
- Capture the **full page** including the logo, form, and any branding
- This is the first impression — make sure the background and branding look clean

### 2. Director Dashboard (Overview)
**File:** `02-dashboard.png`
- Log in as Director
- Capture the **main dashboard** with stats cards (students, teachers, classes)
- If there are charts visible, even better
- Crop to show the **top portion** with stats and any welcome message

### 3. Results View — Subjects as Columns (The Pivot Table)
**File:** `03-results-pivot.png`
- Go to **Results Management > View Results**
- Select a class (e.g., "Grade 8A"), a term, and an exam type
- Wait for results to load
- Capture the **full results table** showing student names on the left and subject shortcut columns (MATH, ENG, BIO, etc.)
- This is your **hero screenshot** — it shows the clean, spreadsheet-like interface

### 4. Results Entry — Inline Score Editing
**File:** `04-results-entry.png`
- Go to **Results Management > Result Entry**
- Select a class and term
- Hover over a score cell so the **edit button** appears
- Capture the table showing scores with grade badges and the inline editing UI
- Shows teachers how easy it is to enter grades

### 5. Report Card (PDF)
**File:** `05-report-card.png`
- Go to **Report Hub** or **Results Management > Reports**
- Select a class and generate a **Class Report Card PDF**
- Open the PDF in your browser or PDF viewer
- Capture **Page 1** of a single student's report card
- If you have a template with school logo and QR code, use that one
- This is the **end product** parents and students see

### 6. Mark Schedule
**File:** `06-mark-schedule.png`
- Go to **Results Management > Mark Schedules**
- Generate a mark schedule for a class
- Capture the full mark schedule table or the PDF output
- Shows the subject-by-subject mark breakdown

### 7. Digital Stamp Designer
**File:** `07-stamp-designer.png`
- Go to **Digital Stamps > Designer**
- Show a stamp template being designed (circular or rectangular)
- Capture the canvas with the stamp preview
- This is a **unique differentiator** — no other Zambian SaaS has this

### 8. Public Verification Page
**File:** `08-verification.png`
- Go to any issued document's verification page (or use `/v/{code}` with a real code)
- Capture the **full verification page** showing:
  - Green "VALID" status badge
  - Document type and serial number
  - Issuing institution
  - QR code
  - Date/time
- Shows how **anyone** can verify a Smart Tech document

### 9. Assessment Configuration
**File:** `09-assessment-config.png`
- Go to **Assessment Config**
- Select a class and subject
- Capture the table showing weighted assessment types (e.g., CAT 20%, Mid-Term 20%, Final 60%)
- Shows the **flexibility** of the grading system

### 10. Parent Portal
**File:** `10-parent-portal.png`
- Log in as a **Parent** (or capture the parent dashboard view)
- Capture the child's results overview with grade colours and subject breakdown
- Shows parents what they'll see — this sells the system to school administrators

### 11. Student Portal
**File:** `11-student-portal.png`
- Log in as a **Student**
- Capture the student dashboard showing their results, subjects, or homework
- Shows the student-facing experience

### 12. Analytics Dashboard
**File:** `12-analytics.png`
- Go to **Analytics** or **Result Analytics**
- Capture any charts: grade distribution, performance trends, or subject comparison
- Shows the **intelligence** behind the system

### 13. Communications Hub
**File:** `13-communications.png`
- Go to **Communications**
- Capture the messaging interface showing SMS/Email/WhatsApp options
- Shows the **multi-channel** capability

### 14. Mobile App (if available)
**File:** `14-mobile-app.png`
- If you have the Expo/React Native app running, capture the home screen or results screen
- If not, skip this — we can use a **phone mockup frame** in Canva with the web version

### 15. Fees / Online Payments
**File:** `15-payments.png`
- Go to **Fees** or **Online Payments**
- Capture the payment interface showing MTN/Airtel/Zamtel options
- Shows the **financial management** capability

### 16. Homework
**File:** `16-homework.png`
- Go to **Homework** as a teacher (showing assignment list)
- Or as a student/parent (showing pending assignments)
- Shows the **assignment management** feature

### 17. Attendance
**File:** `17-attendance.png`
- Go to **Attendance** or **Attendance Register**
- Capture the attendance marking interface or stats
- Shows the **daily operations** feature

### 18. Certificate Designer (Bonus)
**File:** `18-certificate.png`
- Go to **Certificate Designer**
- Show a designed certificate on the canvas
- Visual and impressive — good for the flyer

## Capture Tips

| Tip | Why |
|---|---|
| Use consistent data | Same class, same term across screenshots for visual coherence |
| Hide browser bookmarks bar | Cleaner screenshots |
| Use full-screen mode (F11) | Removes browser chrome |
| Capture at 100% zoom | Consistent sizing across all screenshots |
| Use a clean school profile | Remove any dev/test artifacts |
| Name files exactly as shown | Makes Canva organization easy |
