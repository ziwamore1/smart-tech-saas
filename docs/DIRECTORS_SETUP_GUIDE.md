# SmartTech — Director's Setup Guide

> **Follow these steps after your first login to set up your school**

---

## Step 1: Complete Your School Profile

1. Go to **Settings** in the sidebar
2. Enter your **school name**
3. Select your **institution type**: Primary School, Secondary School, Advanced Secondary, College, or University
4. Save changes

---

## Step 2: Set Up Academic Year

1. Go to **Academic Years** (or **Settings** → **Academic Year**)
2. Click **+ Create Academic Year**
3. Enter the year name (e.g., "2026 Academic Year")
4. Set the **start date** and **end date**
5. Add **terms** (e.g., Term 1, Term 2, Term 3)
6. Click **Save**

---

## Step 3: Add Your Staff

### Option A: Add Users Individually
1. Go to **Users**
2. Click **+ Add User** (or use **Teachers** → **+ Add Teacher**)
3. Fill in their details: name, email, phone, department
4. Assign their **role** (Head Teacher, Teacher, etc.)
5. Click **Save**

### Option B: Invite via School Members
1. Go to **School Members**
2. Click **+ Add Member**
3. Search for the user by name or email
4. Click **+ Add**
5. Assign their role using the **+ Role** button

---

## Step 4: Create Classes

1. Go to **Classes**
2. Click **+ Add Class**
3. Enter the class name (e.g., "Grade 1A", "Form 2B")
4. Select the **level type** (Grade, Form, etc.)
5. Set the **capacity** (max students)
6. Select a **grading system**
7. Click **Create**

**Repeat for all classes in your school.**

---

## Step 5: Assign Class Teachers

1. Go to **Classes**
2. Click the **🏫 icon** on a class card
3. Select the **Teacher** to assign
4. Select the **Academic Year**
5. Check **"Primary class teacher"** for the homeroom teacher
6. Click **Assign**

---

## Step 6: Add Subjects

1. Go to **Subjects** (or **Classes** → 📚 icon)
2. Create subjects: Mathematics, English, Science, etc.
3. Assign subjects to classes

---

## Step 7: Add Students

1. Go to **Students**
2. Click **+ Add Student**
3. Enter student details: name, date of birth, gender
4. Select the **class** to enroll them in
5. Add **parent/guardian** info
6. Click **Add Student**

---

## Step 8: Set Up Grading

1. Go to **Settings** → **Grading Systems**
2. Review the default grading system
3. Customize if needed (e.g., add your school's specific grade boundaries)

---

## Step 9: Configure Notifications

1. Go to **Settings** → **Notifications**
2. Enable notifications for:
   - Student absences (notify parents)
   - Exam results published
   - New messages
3. Set your preferred notification method (email, push, both)

---

## Step 10: Test the System

1. Ask a teacher to login and verify they can see their classes
2. Ask a student to login and verify they can see their timetable
3. Ask a parent to login and verify they can see their child
4. Take attendance and verify parents get notified

---
